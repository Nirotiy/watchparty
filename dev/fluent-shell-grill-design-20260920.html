确认记录

本轮范围Banguru 入口、Linkle 大厅、详情、创建与加入弹窗、通知、侧栏、底栏。房内队列、聊天、成员仅同步基础主题，不改布局交互。播放器画面和叠加控件不变。
主题与材质深色／浅色／跟随系统，首次深色，立即生效并保存。材质跟随系统／关闭，兼容性验证通过后默认跟随系统。标题栏不显示重复名称。
Mica 边界窗口背景、标题栏、主导航使用系统材质；内容区保持可读背景，视频不叠材质。系统不支持、关闭透明、高对比度时纯色回退。HTML 只表示区域与色调，不证明 Mica 已接入。
必须暂停的情况Mica 需要重建窗口、改变视频承载结构或中断活动会话时，先报告技术代价，等待确认。
会话与草稿搜索、筛选、滚动本次运行保留。底栏始终指向活动会话，切换成功才更新。跨服务不提供快捷加入。播放草稿离开分类时提供保存／放弃／继续编辑。
弹窗空表单支持 Escape、关闭按钮、遮罩。填写后遮罩不关闭，Escape／关闭需确认放弃。提交中禁止重复提交与关闭，直至结果或超时。
键盘与布局Ctrl+K 或 / 聚焦搜索，输入中不拦截 /。方向键选择，Enter 打开详情，明确按钮加入。Escape 关闭最上层面板并恢复焦点。最小 960×640，底栏 64px。

实施与验收顺序

  1. 核对 facade 和会话事务接口，先报告设计与接口差异。
  2. 统一 Fluent 主题与公共控件，再迁移所选页面。
  3. 独立验证 Mica 与透明 Electron、Rust/libmpv 合成的兼容性。
  4. 覆盖深浅色、未保存草稿、弹窗提交、Toast、焦点恢复和跨服务隔离。
  5. 区分代码测试、Electron 真窗口、Windows DPI 与真实可听输出证据，保留未验证项。

本稿不连接服务，不保存输入，也不模拟房间加入成功。两套方案只用于选择视觉组织方式；选择后才接入真实 React 组件。
