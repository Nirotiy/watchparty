WatchParty 桌面客户端 · 重设计方案

基底 Linear（纯黑画布、发丝边框、紧凑密度），强调色 sky-400 与 web 端同源，YouTube 只取拓扑，MasterClass 只借媒体画幅的电影感。每套方案右上角可切换深浅主题（浅色为硬需求，深色为默认）。所有界面为高保真静态稿，数据为示意。

方案 A

指挥台

Linear 纯血。常驻图标导航栏 + 三栏指挥布局：房间状态、队列、成员常驻可见，播放画幅是工作区的一部分而不是主角。信息密度最高，适合把客户端当控制台重度使用的用户。代价：媒体画幅偏小，观影仪式感最弱。

方案 B

放映厅

MasterClass 的媒体呈现方式 + Linear 的克制表皮。画幅是主角：宽幅媒体区置于视觉中心，媒体库为海报网格，控制悬浮于画幅底部。无持久侧栏，层级全部纵向展开。代价：多任务下的并排信息可见度低于 A，队列需要展开动作。

方案 C

工具台

YouTube 的拓扑、Linear 的表皮、放映厅的全宽画幅。播放页是特殊的全出血面：无左轨、无顶栏、无状态栏，画幅铺满窗口，信息收纳进上下两条自动隐藏的 overlay（对齐浏览器端播放页）；其余页面（首页 / 媒体库 / 设置）保留 44px 折叠轨。队列与成员从 overlay 顶栏开启，抽屉自右缘滑出。代价：全屏沉浸下入口都在 overlay 里，依赖指针/键盘唤起。
