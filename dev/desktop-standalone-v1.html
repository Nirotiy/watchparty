目标定义

用户安装应用后，无需打开浏览器即可：配置服务器与站点凭据 → 建房或房号/PIN 入房 → 成为房主并管理房间与队列 → 浏览 OpenList / 添加 HTTPS·HLS 媒体 → 播放、同步、恢复最后房间、调整播放器设置 → Windows 安装包交付。网页 handoff 降级为可选捷径。

架构不变量（所有 Gate 必须遵守）

  • WebView 只做 UI，不持有 Basic Auth、access/owner token、媒体直链或任意 mpv 命令；所有秘密与网络逻辑在 Rust。
  • desktop 是正式身份类型；服务端不伪装 browser；不改房间临时内存生命周期。
  • 沿用 Rust 原生 HTTP + 条件轮询；不把 Socket.IO 放进 WebView。
  • 禁止原始 mpv.conf、脚本、任意命令 IPC；设置全部白名单化。
  • 不触碰生产环境；每 Gate 以测试 + typecheck 全绿收口。

Gate 1 已完成：单站点配置与系统凭据

  • 非敏感配置（backend origin、昵称、主题、播放器偏好）持久化到 AppData；本 Gate 实现站点 Basic Auth 的 Windows Credential Manager 存储。房间 token、ownerToken、generation 的持久化与恢复在 Gate 2 一起实现，当前仅保留原生内存会话。
  • 密码用 Windows 原生凭据对话框录入，不经过 WebView（HTML 密码框方案因 JS 字符串不可擦除被否决）。
  • backend origin 仅允许 HTTPS（loopback 可 HTTP），连接需验证；设置页提供验证/更新/清除。
  • 主题与普通偏好保存不重建 runtime；只有站点变化或凭据更新/清除结束旧会话。耗时工作在后台串行执行；界面清空旧房间，重新加入必须使用新票据。
  • 站点变更先验证、准备替换实例，再原子保存配置；准备或保存失败保留旧会话与旧配置。凭据已改变而重建失败时停止旧 transport，禁止继续使用旧密码。
  • 退出：缺省无站点时不创建联网 runtime；无站点环境变量可配置并连本机测试服务；日志、DevTools、命令行无凭据。DLL 打包仍属 Gate 8。

Gate 5 播放与字幕闭环

  • libmpv 支持 OpenList / HTTPS 文件 / HLS；不做 YouTube、Magnet、本地文件。
  • 保持 direct → 单次重解析 → fallback 链（URL 信任规则 Gate 0 已生效）。
  • OpenList 外挂字幕（ASS/SSA/SRT/VTT）由 Rust 下载进受控临时目录并清理；内嵌 + 外挂轨道选择。
  • 保留自动追帧 + 本地 resync 兜底（不广播）。
  • 退出：三类媒体 + 两类字幕在 desktop/browser 混合房间稳定同步。

Gate 6 白名单播放器设置

  • 视频：硬解 auto-safe/auto/off、去隔行 auto/on/off、HDR auto/转SDR/原样。
  • 音频：输出设备（消失回退系统默认）、声道 自动/立体声、默认音量、首选语言；不做 bitstream 直通。
  • 字幕：语言顺序、字体、相对字号、ASS 覆盖开关、当前媒体字幕延迟。
  • 网络：缓存预设（自动/低延迟/稳定）+ 类型化超时；不做代理/自定义 CA/DNS。
  • 每项定义生效时机（即时/下次载入/重建播放器）与失败回滚。
  • 退出：每个公开设置有类型、范围、fallback 与至少一个真实媒体用例。
