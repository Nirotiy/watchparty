WatchParty 桌面客户端 · 实现级设计 Brief（一期）

方案 C′「工具台 · 悬浮抽屉」已确认（dev/desktop-redesign-mockups.html）。本文回答 desktop 侧交接的六个问题，全部基于当前 src-tauri 契约与 desktop-shell 现状（601 行 vanilla）核实，不引入猜测。适用分支：feat/tauri-desktop-gate0-3 及后续。

一、技术栈：保持 vanilla，不迁 React + shadcn/ui

一期决定：现有纯 HTML/CSS/JS（ES modules），零构建、零新依赖。
  • 现状 desktop-shell/ 共 601 行（html 103 / css 245 / js 253），frontendDist: "../desktop-shell" 直出原始文件，CSP script-src 'self' 允许本地多文件脚本。
  • 一期界面规模 = 4 屏 × 双主题，复杂度集中在状态渲染而非组件数量；React + shadcn/ui 需要引入 vite 构建链、node_modules 依赖树、Tauri 构建配置改动——收益不抵扰动，尤其 desktop 会话正在活跃开发 Rust 侧。
  • 组织方式：单文件拆为 js/state.js（状态归约）/ ipc.js（invoke 封装）/ views/*.js（每屏一个渲染函数），沿用 window.__TAURI__.event.listen。DOM 渲染用模板字符串 + 顶层 render(state) 纯函数（现状 renderState 已是这个形态，扩展即可）。
二期迁移触发条件（满足其一再议）：出现复杂表单校验/聊天流；需要与 web 端共享组件；界面超过 8 屏。迁移预留：CSS 只用自定义属性 token（见五）、语义 class、无框架耦合的 DOM 结构。

二、desktop://state 各状态的展示映射

渲染层监听的是 DesktopEvent::State { state: DesktopUiState }（Tauri event，非 URL scheme）。DesktopUiState = { connection, room, members, player, capability, error }，connection ∈ Connecting | Ready | Backoff | Expired | Failed。映射：

connection主区展示顶部状态条控件可用性
Connecting骨架占位（静态色块，禁 pulse）「正在连接后端…」中性全部禁用
Ready 且无 room.source空态 CTA：「房间内还没有媒体，打开媒体库点播」→ 跳媒体库页「已连接，等待房间媒体」播放类禁用；媒体库/设置可用
Ready 有源正常三栏（画幅/抽屉/轨）「已连接 · 同步偏差 Nms」按角色启用
Backoff画面冻结在最后快照，不加遮罩琥珀色「网络暂时不可用，正在重试」播放控制保留（本地可用项），写操作禁用
Expired全屏覆盖卡：「桌面会话已过期」+ 加入表单（重开 startDesktopSession）错误红仅表单可用
Failed全屏覆盖卡：脱敏错误码（DESKTOP_REQUEST_FAILED 等）+ 重试按钮错误红仅重试可用

另有 Ready 下的子状态：player.loaded === false → 画幅区「等待媒体加载」占位（带 resolve 重试说明）；error.message 非空（如已切 fallback）→ 画幅上沿一次性提示条「直连失败，已切换服务器中转」，10s 自动消失（纯 CSS，无 JS 定时重绘）。

一期缺口-1：倒计时展示需要 Rust 侧在 DesktopUiState 增加 retryAt 字段（session.rs 已有 retry_at 内部值，只差序列化）。不加则一期显示静态文案。

三、三个 IPC 入口的控件映射

invoke 命令签名（现状）调用控件
startDesktopSession(ticket)首页「加入/恢复」按钮（ticket 交接流）、PIN 门禁提交后、watchparty:// deep-link 自动启动、Expired 覆盖卡的重新加入
executeRoomCommand(DesktopCommand)播放/暂停 Play|Pause；时间轴 Seek；倍速 Rate；音量 Volume（本地）；音轨 SelectAudioTrack（本地）；字幕 SelectSubtitleTrack（本地）；显示/隐藏播放器 PlayerVisibility；全屏 Fullscreen（后四者由 tauri_api.rs 拦截本地处理，不进房间传输）
stopDesktopSession()「离开房间」按钮、Expired 卡的退出、窗口关闭钩子
一期缺口-2（IPC 扩展清单，需 desktop 会话新增）：A1「全功能」超出当前 3 命令的部分——
  • joinRoom(roomId, pin, nickname)：房号+PIN 直加入（现在只有 ticket 入口；Rust 侧 transport 已有 HTTP client，补 REST /access 调用即可）
  • createRoom(...)、listMedia(root, path, cursor)、searchMedia(q)：房间创建与媒体库浏览（复用现有 REST）
  • fetchThumbnail(mediaId) → data URL：海报图。CSP img-src 'self' data: 禁止远程图，必须由 Rust 抓取转 base64（含本地缓存）。一期降级方案：媒体库先用无海报网格（文字+元数据，设计稿已按此绘制）
  • setSiteCredentials(u,p) / clearSiteCredentials()：写系统凭据库并接通 SiteBasicAuth（native 侧已存在，缺录入 UI 的 IPC）
  • queue 类房间命令（playlistAdd/Play/Next 等）当前是否在 DesktopCommand 白名单内需 desktop 会话确认；缺则补

四、状态设计补充（含文案）

  • 加载：一律静态占位 + 文案（「正在生成交接码…」「正在连接…」「正在解析媒体…」），禁止 spin/pulse（spec 禁令）。首次进入每屏允许一次性 fade-in（150ms，prefers-reduced-motion 关闭）。
  • backoff：不做倒计时（依赖缺口-1）；文案「网络暂时不可用，正在自动重试」。连续 backoff 超过 2 分钟追加「检查后端地址与网络」。
  • expired：覆盖卡三要素——原因（票据/会话过期）、动作（粘贴新交接码或房号加入）、退出入口。不自动重试（防循环）。
  • 无媒体：空态 CTA 一个动作入口（打开媒体库），不堆说明文字。
  • 播放失败：Rust 侧已实现「resolve 重试一次 → 切 fallback」；UI 只呈现结果态（「已切换服务器中转」提示条），失败终态复用 Failed 覆盖卡。UI 不重复发起 resolve（避免与 native 重试叠加）。

五、播放控件最终行为

控件行为通道
播放/暂停切换 Play|Pause；按钮文案跟随 room.paused房间命令（同步）
时间轴点击/拖拽 → Seek(positionSeconds)；player.loaded=false 或时长≤0 时禁用；时间码 mm:ss / mm:ss 等宽字体房间命令

六、图标、字体、静态资源

  • 图标：Material Symbols Outlined，与浏览器端前端完全同源同字形（web 已引入 material-symbols 包）。桌面端把用到的字形打包为本地 sprite 或子集字体放进 desktop-shell/（CSP img-src 'self' / style-src 'self' 允许），禁止 lucide 与 material 混用、禁止运行时 CDN。播放页字形清单：skip_previous / play_arrow / pause / skip_next / volume_up / subtitles / speed / fullscreen / fullscreen_exit / add / monitor（显示播放器）/ visibility_off（隐藏播放器）/ queue / group / library / logout。
  • 字体：一期 system-ui 栈（中文回退 微软雅黑/苹方），零资产零加载，与设计稿渲染一致；品牌字体（如 Söhne 类）二期以子集化 woff2 打入 desktop-shell/fonts/（CSP style-src 'self' 允许 @font-face 本地文件）。
  • token 表：深浅两套自定义属性随 <html data-theme="dark|light"> 切换（用户偏好持久化需 desktop 会话开 Tauri store 或落 localStorage——CSP 未禁，但沙箱策略需 desktop 确认；一期可默认深色 + 手动切换不持久）。数值沿用设计稿：深 bg #000 / card #0d0f13 / line #1f242b，浅 bg #fff / card #f6f7f9 / line #e4e7eb，强调深色 sky-400 #38bdf8、浅色 sky-600 #0284c7，圆角 6/8/10px，密度 4px 基。
  • 无其他静态资源：无图片素材（媒体库海报见缺口-2）、无音频、无视频资产。
