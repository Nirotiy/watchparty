WatchParty 桌面客户端 · Fluent 形态探索

三套侧栏导航 + Mica/Acrylic 的桌面应用形态，覆盖首页 / 播放页 / 媒体库 / 设置全流程。Mica 以基色 + 两块静态渐变模拟，Acrylic 以半透明层 + 模糊标注模拟（均无持续重绘动画）。播放页交互契约沿用方案 C′（全出血、2.4s 自动隐藏、抽屉常显）。状态：混合基线 AB 已确认定稿（2026-09-04），实施交接见 dev/desktop-baseline-ab.html；A / B / C 保留作备选参考。

混合基线 AB A 首页/设置 + B 播放器 · 控件集对齐现有实现

定位：首页与设置采用方案 A 骨架（常驻侧栏 + Mica）。播放页控件严格对照现有实现（web Controls.tsx + desktop room-view.tsx + brief 命令表），不做 mpv OSC 的照搬：顶部中央只留房号 / 同步延迟 / 队列 / 成员；其余控件全部沉入底部两行——贴底全宽 seekbar（时间码压两角、含缓冲区间与悬停时间戳）+ 其上方的裸图标行（无卡片边框，Acrylic 渐变衬底）。房间级控制（播放暂停 / 下一项 / seek / 倍速）仅房主可用，沿用 SharedControl 禁用 + 锁因提示；同步以引擎自动追帧为主，第二行的「重新同步」按钮仅作手动兜底（实现上就是一条 seek 到房主位置，无需新命令；不设独立 Sync 按钮，循环开关因桌面命令表无 loop 命令而移除）；本地控制（音量 / 音轨 / 字幕 / 挂起 / 全屏 / 添加媒体）人人可用。mpv 截图特有的截图 / 流信息 / 书签 / A-B 循环 / 上一项不入列。
