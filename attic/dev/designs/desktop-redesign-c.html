WatchParty 桌面客户端 · 方案 C′ 设计基线

本文件是方案 C′ 的唯一设计基线：首页统一入口（智能输入框）、全出血播放页（上下 overlay 自动隐藏、无侧栏）、媒体库网格、站点凭据设置。深浅双主题（右上角切换）。字形为 Material Symbols Outlined 示意——正式实现使用与浏览器端同源的 material-symbols 包。

交互规格（实现契约）
  • 播放页 = 全出血面：无左轨 / 顶栏 / 状态栏；页面切换经顶部 overlay。
  • overlay：指针移动 / 按键唤起，2.4s 无操作隐藏（150ms ease-out，prefers-reduced-motion 关闭）；抽屉打开时常显。
  • 抽屉：右缘滑出 min(360px, 45%)，实色表面 + 左边框，不挤压画幅；队列 / 成员各一个，同一时间只开一个。
  • 左轨 = 唯一入口（房间 / 队列 / 成员 / 媒体库 / 设置）；队列与成员未加入房间时置灰。
  • 首页智能输入：房号 / watchparty:// → 加入（受保护 401 后行内 PIN）；媒体直链 / m3u8 / YouTube → 创建并开播（创建者为房主，房间默认锁定）。
  • 上次房间仍存活时显示恢复条，否则整条隐藏。
