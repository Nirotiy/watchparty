一、决策摘要

  • 应用壳（首页 / 媒体库 / 设置）：采用方案 A 骨架——232px 常驻侧栏（Win11 设置风，Mica 底），替代当前折叠轨。
  • 播放页：顶部中央只留 房号 / 连接状态 / 队列 / 成员 四项；其余控件全部沉入底部两行（贴底全宽 seekbar + 上方裸图标行）。不照搬 mpv OSC。
  • 控件集严格对齐现有实现（web src/components/Controls/Controls.tsx + desktop desktop-shell/src/components/room-view.tsx + desktop-shell/src/lib/contracts.ts）。mpv 专属项不入列：截图、流信息、书签/章节、A-B 循环、上一项、循环开关。
  • 同步：引擎自动追帧为主；不设独立 Sync 按钮。第二行设「重新同步」按钮作手动兜底（见第三节，需要新本地 IPC）。
  • 交互契约沿用 C′：全出血画幅、指针/键盘唤起、2.4s 自动隐藏（150ms ease-out，prefers-reduced-motion 时关闭）、抽屉打开时 overlay 常显。

3.4 「重新同步」的本地 IPC（唯一需要动的契约）

关键约束：非房主成员不能通过房间级 seek 命令追进度——那会把整个房间拖到自己的位置。重新同步必须是纯本地操作：Rust 根据 positionSeconds + (estimatedServerTimeMs - serverTimeMs) × playbackRate 计算播放中的当前权威位置（暂停时不累加），再让本机 libmpv seek；不产生任何房间命令、不触发回传。
  • 现状：DesktopCommand（contracts.ts L88-98）没有本地 seek；volume / fullscreen / playerVisibility 走的是「tauri_api.rs 本地拦截、不进房间传输」模式（见 dev/desktop-redesign-brief.html 命令表）。
  • 实现：新增仅含类型的 { type: "resync" }。WebView 无权提供位置、URL、Header 或 mpv 命令；DesktopSession 在进入 room transport 前拦截，使用校准时钟计算目标并本地 seek，不广播；追帧引擎后续照常收敛。
  • 验收点：非房主点击后，其他成员（含 mpv 插件端、web 端）的 snapshot 不得出现由该操作引起的 revision / position 变化；本机画面应跳至房主位置附近。

四、应用壳改动（P1）

  • 侧栏：232px 常驻（Win11 设置风）：品牌字、导航项 首页 / 房间 / 队列 / 成员（后两项无房间时置灰）/ 媒体库 / 设置；底部常驻连接状态、运行时状态与 libmpv 能力。不放无行为的搜索/连接假输入。
  • 窗口底色：Mica 用基色 + 两块静态渐变模拟（同现有 index.css 手法），禁止持续重绘动画（无脉冲/闪光/模糊循环）。
  • 首页：保留真实的一次性交接入口；房间存活时显示会话摘要与返回播放按钮。最近播放明确标注本阶段不记录，不生成假历史。
  • 媒体库：在受限原生媒体 IPC 尚未接入前显示诚实的不可用状态；设置：只开放真实主题切换，站点凭据说明其未来由 Rust 系统凭据库承载，不绘制不可用假表单。
  • 播放页保持全出血：进入 room 视图时侧栏隐藏（全出血契约），返回由侧栏导航承载——与现有 suspendedForNavigation 挂起逻辑对接，勿破坏。

五、禁止事项

  • 不新增房间协议命令（UNIVERSAL_ALIGNMENT_SPEC.md 不动）；唯一允许的契约扩展是 3.4 的本地 resync IPC。
  • 不做：循环、A-B 循环、截图、流信息面板、章节/书签、上一项、独立 Sync 按钮、剧场模式（web 专属）。
  • 不触碰生产环境、线上数据库；不提交密钥。
  • 动效只允许 opacity/transform 过渡（150ms ease-out），禁止持续重绘动画。

六、验收清单

  1. 房主：播放/暂停/seek/下一项/倍速全部生效并同步到 web 端与 mpv 插件端；非房主：上述控件置灰，悬停显示锁因（现有 lockReason 语义）。
  2. 非房主点击「重新同步」：本机画面跳至房主位置，房间 revision 不变，无命令广播（服务端日志验证）。
  3. 音量 / 字幕 / 音轨 / 挂起 / 全屏 / 添加媒体 / 离开：各自行为与现版本一致，仅位置变化。
  4. overlay：2.4s 无操作隐藏、指针/键盘唤起、抽屉打开时常显；Esc 退出全屏后图标状态正确。
  5. 真实 MKV 回归：画面嵌入、显隐、最大化、全屏、跨端同步（沿用 tauri-current-execution-plan 已通过的手测矩阵）。
  6. npm test 与 typecheck 全绿；无新增 lint 抑制。
